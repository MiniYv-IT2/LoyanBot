# 27-插件商店前端方案（洛颜商店 Loyan Store + 插件设置）

> 状态：定稿待实施。本文件为前端开发的完整说明书，覆盖页面结构、布局、组件、国际化、后端对齐、测试要求。

## 一、页面结构

```
panel/src/pages/Dashboard/Plugins/
    Store/index.jsx      洛颜商店（插件市场，英文 Loyan Store）
    Settings/index.jsx   插件设置（占位空白，不写任何内容）
```

路由：`/plugins/store`、`/plugins/settings`。

## 二、菜单

左侧菜单栏新增"插件"子菜单（**插在提供商与 AI 工具箱中间**），点击箭头展开两个子项：
- 洛颜商店（Loyan Store）→ /plugins/store
- 插件设置 → /plugins/settings

菜单按钮文字放**现有 i18n 的 dashboard 侧边栏资源**（与其他页面菜单文字一起，`dashboard.sidebar.*`），页面内独立文案放 `plugins.ts`。

## 三、国际化（i18n）

- 每个语言目录（zh-CN/en-US/ru-RU）新建独立文件 `plugins.ts`，**不与其他页面资源混在一起**
- 中文插件商店名必须显示"洛颜商店"，英文"Loyan Store"
- 页面内所有可见文字（按钮/占位符/分类/提示）一律走 i18n，**代码严禁硬编码中文/英文文案**
- 分类名称也走 i18n

## 四、页面布局（洛颜商店）

### 电脑端（桌面）

```
┌─────────────────────────────────────────────────────────┐
│ [插件源按钮▾]        [🔍 搜索框(灰字占位)]    [排序▾]   │ ← 顶部行
├─────────────────────────────────────────────────────────┤
│ 全部 | 娱乐 | 工具 | 管理 | 媒体 | AI | 资讯 | 生活 | 开发 │ ← 分类选项卡行
├─────────────────────────────────────────────────────────┤
│ [卡片][卡片][卡片]                                        │ ← 插件网格 3 列 × 4 行
│ [卡片][卡片][卡片]                                        │
│ [卡片][卡片][卡片]                                        │
│ [卡片][卡片][卡片]                                        │
├─────────────────────────────────────────────────────────┤
│     ◀  1 ... 5 6 7 ... 54  ▶                             │ ← 分页（固定位置）
└─────────────────────────────────────────────────────────┘
```

### 手机端

- 分类选项卡显示在**页面左侧**（固定），与菜单抽屉不同——菜单是抽屉可收起，分类是页面内固定子菜单
- 插件卡片自适应大小，文字不溢出
- 顶部行：插件源按钮 + 搜索框 + 排序（同样可用，窄屏堆叠）

### 顶部行细节

1. **插件源按钮**（左侧）：卡片长条标签样式，长度**只刚好包裹文字**（动态长度），点击出现下拉选项（与语言下拉同款样式），**默认显示官方源**；列出全部已配置源。添加源功能暂不做（等插件设置页面）。
2. **搜索框**（中间）：长方形，内含放大镜图标，渲染灰色占位文字；输入关键词即时过滤——关键词可匹配**插件名称、作者、标签、插件 id**。
3. **排序下拉**（右侧）：默认排序 / 更新时间 / 下载数量 / 作者顺序 / 点赞数量。

### 分类

分类取自插件域定义（docs/25 定稿 9 类）：娱乐 / 工具 / 管理 / 媒体 / AI / 资讯 / 生活 / 开发 / 其他，外加"全部"。

## 五、插件卡片

- 固定大小长方形卡片（不随内容溢出），电脑端一横排 3 张、共 4 排（每页 12 个），手机自适应
- 卡片内部布局（从左到右）：
  - **插件 icon**：左侧，无 icon 时用系统默认 SVG（Ant Design 图标库）
  - **插件名称**：开发者自定义的 `name`（**不是** id / 仓库目录名）
  - **点赞按钮**：可点击点赞（调后端 like 接口）
  - **下载图标**（SVG）+ **下载数量**（纯数字）
  - **安装按钮**
  - **GitHub 按钮**（跳转 repo 页面）
- 卡片文字颜色用主题变量（`var(--text)`/`var(--text-secondary)`），深色主题自动反白（themes.css 已有规则）

## 六、分页组件

- 位置：网格下方**固定位置**（独立组件，抽离到 `panel/src/components/`）
- 结构：左箭头按钮 + 页码区 + 右箭头按钮
  - 左/右箭头为 SVG 图标按钮，点击前后翻页
  - 页码：**第一页固定显示**，最后一页固定显示
  - 当前页附近显示连续页码；中间用省略号（…）连接
  - 例：共 54 页时 `1 … 5 6 7 … 54`；翻到 55 页时省略号后数字递进
- 每页 12 个插件（3 列 × 4 排）

## 七、可抽离组件

- `panel/src/components/PluginPagination.jsx`：分页导航（箭头 + 页码 + 省略号）
- `panel/src/components/PluginSearch.jsx`：搜索框（放大镜 + 灰字占位）——按需抽离
- 组件目录：`panel/src/components/`（已有 Captcha/LanguageSelector 等）

## 八、后端接口对齐

| 前端需求 | 后端接口 | 状态 |
|---|---|---|
| 插件列表（含 likes/downloads/installed/update_available）| `GET /api/loyanui/store/plugins` | ✅ 已含 downloads（本次补充）|
| 点赞 | `POST /api/loyanui/store/plugins/<id>/like` | ✅ |
| 插件源列表 | `GET /api/loyanui/store/config`（sources 数组）| ✅ |
| 安装/更新 | `POST /store/plugins/<id>/install|update` | ✅ |
| 排序/搜索/分类 | 前端本地过滤排序（数据量小，后端返回全量）| ✅ |

## 九、主题适配

- 按钮/高亮用 `var(--primary)` / `var(--primary-hover)`（跟随主题色）
- 文字一律 `var(--text)` / `var(--text-secondary)`，深色主题自动反白，避免覆盖不可见
- 参考 `panel/src/styles/global.css`（布局/媒体查询）+ `themes.css`（主题变量）
