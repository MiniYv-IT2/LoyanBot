## 二、Container 设计（新增，~100 行）

```python
class Container:
    def __init__(self): self._registry = {}; self._instances = {}
    def register(self, name, factory): self._registry[name] = factory
    def get(self, name):
        if name not in self._instances:
            self._instances[name] = self._registry[name](self)
        return self._instances[name]
```

- 工厂收 `self`（Container），组件在工厂里声明依赖
- 不是服务定位器：业务代码不 import Container，只在装配点使用
- 模块级默认实例保留（兼容现有 import），但类本身不自杀单例（可测试）

## 四、接口约束（硬性）

- **不改任何现有 API 名称/签名**：`reload_instance/start_instance/stop_instance/rename_instance`、`loyan_send_msg`、`plugin_manager`、`event_bus`、`adapter_pool` 等
- 模块级默认实例必须保留（向后兼容）
- 新增接口风格与现有一致（函数/类命名风格）
- 不引入第三方 DI 库（手写轻量 Container）
