# v0.1.dev0 (2026-07-31)

面板迁移至核心 webserv、热重载与消息链路修复、扫码登录实例修复。

## 面板迁移至核心（webserv/panel）
- 面板从 `loyan/plugins/LoyanUI/` 迁移至 `loyan/core/webserv/panel/`
- 新目录结构：`api/`（auth/adapters/providers/monitor）、`service/`、`auth/`、`server.py`、`static.py`、`commands.py`
- 旧插件 `metadata.toml` 移出禁用，目录保留作参考
- `webserv/routes.py` 删除（health/metrics/status 迁入 `api/monitor/`，错误处理器为死代码）
- 内置命令注册表：`register_builtin_command()`（不进 graci，插件开发者不可见），`/panel` 以 `require_admin=True` 注册

## 热重载与消息链路修复
- **热重载 Runtime 同步**：`reload_instance()` 更新 Runtime 的 `adapter_tag` 并重新注册，避免消息回退到旧实例
- **start_instance 补建 Runtime**：扫码登录等新建实例此前不创建 Runtime，事件找不到来源 Runtime 时回退到残留的旧 runtime，导致消息发不出去
- **stop_instance 注销 Runtime**：停止实例时同步注销 RuntimeRegistry，防止残留
- **`_build_runtime()` 提取**：启动加载与动态启动共用同一 Runtime 构建逻辑（Pipeline + 日志 + 注册）
- 默认适配器保留：热重载后若原实例为默认，新实例保持默认

## QQ Official 扫码登录实例
- 扫码登录创建的实例 `QQClaw_ipgk` 连接正常（Token + Gateway + WebSocket）
- 修复后消息可正确路由到新实例并回复
- 实例配置仅含平台字段（platform/bot_name/app_id/app_secret/enabled），管理员通过 `/master_set` 绑定

## 面板功能
- 适配器 CRUD：创建/编辑/删除（数学验证码）/启停/热重载/重命名
- 主题系统：6 套主题（mist/white/pink/purple/orange/dark），CSS 变量 + localStorage 持久化
- 侧边栏折叠：80px 折叠宽度，内容区 margin 过渡
- 登录页渐变：独立 `--login-bg-end` 变量修复 `var()88` 拼接失效
- 移动端适配：适配器列表两行布局

## 内置命令 bug 修复
- `_dispatch_registered` 之前永远返回 `None`，内置命令命中后 process 不短路、继续走后续逻辑
- 修复：命中返回 ctx（已消费）、未命中返回 None

## 测试
