# v0.1.dev0 (2026-08-01)

事件体系落地、插件管控收口、main 拆分、全局模块化。

## 事件体系（三层模型）
- 三层事件：消息事件 LoyanEvent（按 tag 路由）/ 业务事件 BusinessEvent（全广播）/ 生命周期 LifecycleEvent（顺序执行）
- `event/` 目录重构：`__init__.py` 132→26 行（只导出），核心拆到 `bus.py` + `types.py`
- **71 个事件类型**（10 域：消息/群组/好友/平台/实例/插件/通知/系统/用户/AI），每个事件配强类型 Payload dataclass + `validate_payload()` 校验
- `EventBus.publish_business()`：全广播、`biz:*` 通配订阅、错误隔离、30s 超时、cancel 拦截、发布统计、500 条环形缓冲
- 健康统计复用 lifecycle 的 MetricsCollector，不重复造轮子

## 平台事件转换（锁接口不锁文件）
- 基类新增可选方法 `parse_business_event()`（默认 None，不实现则忽略）
- onebot 全量 notice 转换（群增减/群管/禁言/撤回/好友/文件，9 类，business.py）
- satori（member_added/removed、friend_request）、telegram（chat_member 更新/服务消息，business.py）、qq_official（平台不支持返回 None）
- 适配器收到非消息事件不再丢弃 → publish_business

## 插件订阅 API
- graci 新增 `on_event(event_type, priority)` 装饰器（插件专属，字符串/枚举均可）
- brain 等核心包不碰 graci，直接 `event_bus.subscribe` 原生

## 插件管控收口
- 插件注册唯一入口 = 目录扫描：`_merge_decorator_registry` 删除 else 分支，孤儿装饰器命令不再凭空造插件
- `_register_decorated_function` 加调用栈校验，框架核心模块越权注册直接报错
- brain 命令改走内置指令 `register_builtin_command`（/chat /ai /chat reset /persona），不再冒充插件，插件列表干净
- 内置指令支持前缀匹配（`/chat xxx` 命中 /chat）+ ctx.send/reply 注入（提取 `inject_send_reply` 公共函数）

## 面板后端迁移（插件 → 核心 webserv）
- 面板从 `loyan/plugins/LoyanUI/` 迁至 `loyan/core/webserv/panel/`，旧插件 metadata.toml 移出禁用
- 新结构：`api/`（auth/adapters/providers/monitor）+ `service/` + `auth/` + `server.py` + `static.py` + `commands.py`
- `webserv/routes.py` 删除（health/metrics/status 迁入 api/monitor，错误处理器为死代码）
- 面板经 lifecycle 自注册（`AFTER_INSTANCES_READY` → panel_start/panel_commands），main 不再直接调用
- 适配器 CRUD：创建/编辑（PATCH）/删除（数学验证码）/启停/热重载/重命名，`instance_service` 走 `runtime/manager` 公共 API
- 密钥掩码：GET 返回 `前4****后4`，PATCH 掩码值不覆盖（app_secret/token/access_token 等）

## main 拆分与全局模块化
- main.py 566→242 行：实例管理迁出到 `runtime/manager.py`（336 行）
- InstanceManager 类化：构造注入 + 每实例锁 + reload 失败回滚 + 显式状态机，API 名称不变
- 组合根 `container.py`：register/get/build + get_container/set_container，6 叶子组件注册
- PluginManager/SecurityManager/MonitorManager 支持可选构造注入，模块级单例保留
- send/http_routes 容器化（`_get_pool()`/`_get_event_bus()` 容器优先+单例回落）

## Bug 修复
- **telegram 不回消息**：gateway `_async_handle` 漏 `await self._on_event(event)`——协程被创建后直接丢弃，消息收到但不进 pipeline（QQ 一直有 await 所以正常）。历史遗留，非本次引入
- QQOfficial 偶发 `NoneType can't be used in 'await'`（异步回调时序），事件体系重构后消失
- plugin reload 事件用 `PLUGIN_RELOADED`（不在 71 枚举）→ 复用 `PLUGIN_LOADED`
- 插件密钥掩码（GET 返回 `前4****后4`，PATCH 掩码值不覆盖）
