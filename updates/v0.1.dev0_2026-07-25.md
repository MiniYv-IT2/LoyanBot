# v0.1.dev0 (2026-07-25)

项目从 GracyBot 迁移至 LoyanBot，重构命名并新增多项功能。

## 项目迁移
- 包名改为 `loyan`，PyPI 展示名 `LoyanBot`
- 所有导入路径 `gracybot.xxx` → `loyan.xxx`
- CLI 命令 `gracy` → `loyan`
- 日志前缀 `[Gracy]` → `[Loyan]`
- 版本号重置为 `v0.1.dev0`
- `graci` 模块名和 `gracy_` API 函数名保持不变
- 配置文件、Dockerfile、MANIFEST.in 同步更新

## 插件配置管理
- 新增 `config_manager.register_plugin_config()` / `get_plugin()` / `update_plugin()`
- `plugin_conf.json` 配置文件，定义字段类型/默认值/校验规则
- 三层配置链：schema 默认值 < `storage/config/{name}/config.json` < 实例覆盖
- 自动迁移：新增字段自动补入用户配置文件

## 定时调度器
- 新增 `loyan/core/scheduler/` 模块
- 支持 interval / delayed / cron 三种任务类型
- 错误隔离，单任务异常不影响其他

## LoyanUI 面板 (v0.1)
- 基于 React + Ant Design 的全新管理面板
- 登录页：账号密码认证，雾青色主题 #8ecac8
- 密码存储：MD5 + 随机盐，支持 `/panel pwd` 修改
- 默认账号 `Admin`，密码 `@Loyan`
- `/panel` 命令查看访问地址（本地/局域网/公网）
- 构建产物输出至 `loyan/panel-dist/`，打包进 wheel
- 前端 i18n 框架接入（react-i18next），支持中英文

## 其他
- 插件入口标准化为 `main.py`（兼容旧 `{文件夹名}.py`）
- `register_cli_command()` 公共 API 移除
- 许可证改为 GPL-3.0
