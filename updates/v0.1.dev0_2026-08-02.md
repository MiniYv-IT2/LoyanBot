# v0.1.dev0 (2026-08-02)

插件商店全链路落地：后端（源服务/统计/安装更新回滚）+ 前端（洛颜商店页面）+ 指令前缀与别名体系 + 打包资源修复。

## 插件商店后端（新增）
- `plugin_manager.py` 升级：`list_plugins`/`enable_plugin`/`disable_plugin`、`_purge_plugin_modules`（清 sys.modules 前缀）、reload 支持新装、装饰器注册表清理、watchfiles 热重载（300ms 防抖，lifecycle READY/SHUTDOWN 钩子）
- `plugin_store.py`（新增）：多源拉取/缓存（5 分钟 TTL + 失败回落）、聚合（同名去重/版本对比/本地状态/likes/downloads）、压缩包安装（codeload + 镜像链 + 路径穿越拒绝）、更新备份回滚（失败恢复旧版）、`download_base` 中转代理支持（REST 路径 `/plugins/{owner}/{repo}`）
- `plugin_stats.py`（新增）：点赞上传（stats_url）+ 本地已点去重 + 稳定随机降级（md5 % 1001）+ 下载数上报/查询
- 路由：`panel/api/plugins/`（list/enable/disable/reload）+ `panel/api/store/`（列表/安装/更新/点赞/配置，支持 `?force=1` 强制刷新）
- graci 透传 8 个符号：list_plugins/enable_plugin/disable_plugin/reload_plugin/store_list/store_install/store_update/store_like
- 事件补发：安装 PLUGIN_INSTALLED、更新 PLUGIN_UPDATED、失败 PLUGIN_ERROR（原先预留未发）

## 指令前缀与别名体系
- `command_prefix` 从死字段变为可用：匹配层动态解析（互斥模式——改前缀后旧 `/` 命令禁用），内置命令硬编码比较改 canonical 归一化（/关于 /关机 /重启 /开机）
- `command_aliases`（新增）：插件级完整命令别名映射（`{插件名: {命令: [别名]}}`），全局默认 + 实例覆盖
- `user_config.get_effective_cached`：30s TTL 缓存（每消息匹配用，避免频繁读文件）
- 测试隔离：集成测试 autouse fixture mock 前缀配置，避免真实配置污染
